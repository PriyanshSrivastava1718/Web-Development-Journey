    some examples are:
  • using id- using id we can name a particular tag and then anchor tag(<a>) helps use link it using name of id in href

External links

a clickable link inside a webpage which redirects u to an external webpage

    some examples are:
  • using link- using an external link we can ue anchor tag (<a>) helps use link it using href attribute
  • open in different tab- use target="_blank" inside the anchor tag(<a target="_blank">) to open link in a new tab

NOTE: when using target="_blank we also use an attribure that is rel="noopener noreferrer" for more security
